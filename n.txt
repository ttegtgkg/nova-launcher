fix: 搜中文整合包搜不到（CurseForge 会静默忽略中文查询）

现象：搜「化龙」找不到 BeLoong，返回的却是一万条无关整合包，
界面显示 Modrinth 0 / CurseForge 10000。

实测确认根因 —— CurseForge 的搜索接口对中文是「静默忽略」：

  搜「化龙」   -> total=10000，返回结果和「空查询」完全相同
                  （ATM10、DeceasedCraft、Better MC BMC4 … 按人气倒序）
  搜「BeLoong」-> total=1，正确返回 BeLoong
  搜「空」     -> total=10000

也就是说传中文过去等于没传 searchFilter，它把全部热门内容当搜索结果吐回来。
Modrinth 那边也没有中文项目名，所以两个源都是 0 有效结果。

修复：

- i18n 新增 PACK_ALIAS / packAlias()：中文整合包名 → 官方英文名
  （化龙 → BeLoong，更好的MC → Better MC）
- translateQuery 优先查整合包别名，命中直接返回英文名
- cfSearch 内部兜底：翻译后仍含中文就不去搜了，返回空并标记
  chineseUnsupported —— 宁可显示没找到，也不能拿一万条无关结果冒充
- /api/cf/search 路由补上 translateQuery（原来只有 /api/search/all 与
  /api/mr/search 做了，单源搜索这条路径一直漏着）

实测：

  双源搜「化龙」    -> total=1，命中 BeLoong（curseforge）
  搜翻不出来的词    -> total=0，不再返回 10000 条

注：CF 不支持中文检索是上游限制，只能靠词典覆盖常见中文名，
后续遇到搜不到的可以往 PACK_ALIAS / MOD_CN 里补。
