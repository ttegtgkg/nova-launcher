## 二、运行时直接调用其服务 / API 的第三方项目

> 以下项目**没有**把源代码复制进本仓库，本项目通过网络调用其**公开 API / 服务**。按其许可证与使用条款标注。

### 1. BMCLAPI — 下载镜像服务 ⭐

- **作者**：bangbang93
- **项目地址**：https://github.com/bangbang93/BMCLAPI
- **许可证**：MIT
- **使用方式**：本项目在「下载源」中选择 `镜像 / 自动` 时，将 Mojang 官方下载地址替换为 BMCLAPI 提供的镜像地址
  （`https://bmclapi2.bangbang93.com`），用于加速中国内地的游戏本体、依赖库、资源文件下载。
- **归属说明**：镜像服务的全部内容与带宽由 BMCLAPI 项目及其维护者提供，本项目仅做 URL 重写。
  若上游服务不可用，本项目会自动回落到 Mojang 官方源。

### 2. Modrinth — Mod / 整合包 / 光影 / 资源包数据源 ⭐

- **项目地址**：https://github.com/modrinth · **开放 API**：https://docs.modrinth.com/api/
- **使用方式**：调用 Modrinth 公开 API（`https://api.modrinth.com/v2/`）进行搜索、获取项目版本与下载链接、
  解析 `.mrpack` 整合包索引。
- **归属说明**：所有 Mod / 整合包 / 光影 / 资源包的**版权与许可归各自的作者所有**，本项目不重新分发任何文件，
  仅按 Modrinth 提供的下载地址直连下载。每个模组的许可证以 Modrinth 项目页面标注为准，
  使用前请自行阅读对应项目的许可协议。本项目在 UI 中保留了项目原链接与作者信息。

### 8. Aikar's Flags — JVM 内存与 GC 优化参数 ⭐

- **作者**：Aikar（Daniel Ennis）

- **使用方式**：本项目「内存优化」中的 `Aikar 预设` **直接采用** Aikar 公开推荐的 G1GC 参数组合

  这组参数由 Aikar 为 Minecraft 服务端调优并公开发表，被 Paper / Purpur 等服务端广泛采用；
  本项目将其用于客户端并做了说明，**参数数值归原作者所有**。
  启动参数中的 `-Dusing.aikars.flags=https://mcflags.emc.gs` 保留了原始署名链接。

### 13. Microsoft Edge WebView2 — 桌面窗口内核 ⭐

  与 `WebView2Loader.dll`（原生加载器），把启动器界面嵌进**自己的应用程序窗口**，
  从而不依赖外部浏览器的窗口与标签页。

  （Windows 11 与较新的 Windows 10 随 Edge 预装）。若目标机器缺失，外壳会给出明确提示与微软官方下载地址，

## 三、设计思路参考（未使用其源代码）

> 以下项目仅作为**功能与交互设计**的参考对象。本项目**未复制、未翻译、未改写**其任何源代码。
> 代码层面的实现（HTTP 路由、ZIP 解析、下载器、参数拼装、前端 UI）均为本项目自写。

### 1. PCL2 — Plain Craft Launcher 2

- **项目地址**：https://github.com/Meloong-Git/PCL · **许可证**：MIT
- **参考点**：启动器应把「下载 → 版本隔离 → 内存设置 → 模组/资源包管理」串成一条顺畅的路径；
  离线用户名即可开玩；对国内网络友好（镜像优先）。这些是**产品思路**层面的启发。

### 2. HMCL — Hello Minecraft! Launcher

- **项目地址**：https://github.com/HMCL-dev/HMCL · **许可证**：GPL-3.0
- **参考点**：多实例（版本隔离）目录结构、`inheritsFrom` 版本继承的合并方式、
  资源包/光影包目录布局（`resourcepacks/` `shaderpacks/`）等**通用规范**。
- **注意**：HMCL 为 GPL-3.0，本项目**未使用其代码**，因此不受其传染性条款约束；此处仅为致谢。

### 3. Prism Launcher / MultiMC

- **项目地址**：https://github.com/PrismLauncher/PrismLauncher · **许可证**：GPL-3.0
- **参考点**：实例（Instance）概念与 `.mrpack` 整合包格式的解析思路。

### 4. Modrinth App / CurseForge

- **参考点**：整合包内 `mods` / `overrides` 的落地方式，以及 `.mrpack` 格式规范
  （规范文档：https://support.modrinth.com/en/articles/8802250-modpacks-format，归属 Modrinth）。

### 5. BakaXL / XMCL 等其他启动器

- **参考点**：UI 信息层次（版本卡片、下载队列进度展示）的一般惯例，无代码复用。

### 6. 特别说明：关于 PCL2 与本次开发

- 用户提到 PCL（PCL2）被举报的情况。本项目**不是** PCL2 的分支或重打包，与 PCL 项目及其作者**没有任何代码关系**，
  仅在学习「启动器该有哪些功能」时阅读过公开的功能描述。
- 本项目不含任何绕过正版验证、破解、盗版下载的功能。
