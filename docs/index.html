Nova Launcher

新星启动器 · 轻量、开源、为低配电脑与国内网络优化的 Minecraft 启动器

Windows MIT License 零第三方依赖 免费 · 无广告 安装包 35 MB

这是什么

一个用 Node.js + C# 从零实现的 Minecraft 启动器。自带运行环境与桌面窗口， 装完就是一个独立应用，不需要浏览器，也不依赖任何第三方打包工具。

主要功能

实例隔离

每个实例有独立的模组、资源包、光影、存档、截图与配置，互不干扰。

内存优化

启动时按当前可用内存与模组数量自动分配堆大小，并给出可解释的理由。

Java 自动安装

检测不到合适版本时自动下载安装（Amazon Corretto / Microsoft OpenJDK 多源回退）。

内容下载

接入 Modrinth 开放 API，支持中文搜索、拼写纠错与相似名匹配。

存档编辑

直接读取 level.dat，修改游戏模式、难度、作弊开关，保存前自动备份。

下载中心

实时速度、进度、剩余时间，支持取消与失败重试，历史记录持久化。

技术实现

  • 后端：Node.js 原生 http / https / zlib / crypto，零 npm 依赖
  • 桌面外壳：C# WinForms + WebView2，把界面装进自己的窗口
  • 安装程序：C# 手写，用系统自带 csc.exe 编译，无需 Inno Setup / NSIS
  • 前端：手写 HTML / CSS / JavaScript，无框架、无 CDN，完全离线可用

快速开始

从 Releases 下载安装包，双击即可。 

NovaLauncher-Setup.exe        # 图形安装
NovaLauncher-Setup.exe /S     # 静默安装
NovaLauncher-Setup.exe /UNINSTALL /S   # 静默卸载

关于内容来源

本启动器不包含、不重新分发任何游戏本体、模组或整合包文件。 所有内容均按官方公开地址或开放 API 由用户本机直接下载： Minecraft 本体来自 Mojang 官方清单，模组与整合包来自 Modrinth 开放 API。 对于作者关闭第三方下载的文件，启动器不会下载，只提供跳转项目页的入口。
