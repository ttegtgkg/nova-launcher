主题外观

              Nova
            

            

            

              
              
              
            

            
            

              主题就是一个文件，两种写法都行：

              · JSON — {"name":"我的主题","vars":{"--bg":"#111","--accent":"#f0f"}}

              · HTML — <meta name="nova-theme" content="我的主题"> 加一段
              <style>:root{--bg:#111}</style>

              直接把文件拖进窗口也能导入。主题保存在 data/themes/，会跟着数据快照一起备份。

数据快照（自动备份）

            

              每天自动把设置、实例配置、模组来源、存档和键位打包存一份，放在数据目录的
              backups 里，最多留 10 份，超出自动删最旧的。

              游戏本体、依赖库、模组文件不备份 —— 那些能重新下回来，占空间不划算。
