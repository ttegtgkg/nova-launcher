fix: 游戏日志选不中、复制不了

日志面板看起来「不能选中」，根因在去浏览器化的这条全局规则：

  * { user-select: none; }            /* 每个元素都被写成 none */
  .log-box { user-select: text; }     /* 只有容器自己恢复成 text */

user-select 不是继承属性，而且 * 给每个元素写的是显式 none，
所以日志内容外面那层 <span> 依然是 none，把父元素的 text 盖掉了 ——
整段日志一个字都选不中。

修：把可选中区域的后代元素一起列出来（pre * / .log-box * / .detail-desc *
等），让里面包着的 span 也恢复成 text。

另外加了「复制全部」按钮：出问题时要的是把整段日志贴给别人，
手动拖选 800 行不现实。优先用 navigator.clipboard，
被拒时退回选区 + execCommand，两条都不行再提示手动 Ctrl+C。
